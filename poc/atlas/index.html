02 · Combining models

Bagging, boosting, stacking

Ensembles combine several models into one predictor. Each method fixes a different weakness, so it suits different base learners.

BaggingParallel · reduces variance

How
Train the same model on bootstrap resamples, then average (regression) or vote (classification).
Best with
High-variance learners: deep decision trees, neural nets.
Little gain
Stable learners: linear regression, Naive Bayes, kNN.
Examples
Random Forest, Extra Trees, BaggingClassifier, Isolation Forest.

BoostingSequential · reduces bias

How
Each new model fits the errors (reweighted samples or gradient residuals) of the ensemble so far.
Best with
Weak learners: decision stumps and shallow trees (depth 3 to 8).
Watch
Overfits noisy labels; use a learning rate, early stopping and subsampling.
Examples
AdaBoost, Gradient Boosting, XGBoost, LightGBM, CatBoost.

StackingLayered · learns how to combine

How
Diverse base models make out-of-fold predictions; a meta-learner (often logistic or ridge regression) learns to weigh them.
Best with
Models that make different mistakes: trees + linear + kNN + neural nets.
Watch
Always train the meta-learner on out-of-fold predictions, or it learns leaked training fits.
Works with
Any supervised model, plus unsupervised outputs used as features.

Voting & blendingSimple averaging

Hard vote
Majority class wins.
Soft vote
Average predicted probabilities; needs calibrated models.
Blending
Stacking with one hold-out set instead of k-fold. Faster, uses less data.
Unsupervised
Consensus clustering merges many clusterings via a co-association matrix.

Quick rule. High variance (overfits)? Use bagging. High bias (underfits)? Use boosting. Several decent but different models? Stack them. Stacking almost any supervised model is possible; bagging and boosting depend on the base learner, as the matrix below shows.

04 · Measuring

Evaluation methods

Pick the metric by task, and pick the validation scheme by how your data was collected.

Classification

  • Accuracy(TP+TN)/N. Misleading when classes are imbalanced.
  • PrecisionTP/(TP+FP). Cost of false alarms.
  • RecallTP/(TP+FN). Cost of misses.
  • F1 scoreHarmonic mean of precision and recall.
  • ROC-AUCRanking quality across all thresholds.
  • PR-AUCPreferred when positives are rare.
  • Log lossPenalizes confident wrong probabilities.
  • MCCBalanced score, −1 to 1, robust to skew.
  • Confusion matrixCounts per true vs predicted class.

Regression

  • MAEmean|y−ŷ|. Robust to outliers.
  • MSEmean(y−ŷ)². Punishes large errors.
  • RMSE√MSE, in the target's units.
  • R²Share of variance explained, ≤ 1.
  • Adjusted R²R² penalized for extra features.
  • MAPE / sMAPEPercentage error, common in forecasting.
  • Huber lossSquared near zero, linear for outliers.

Clustering

  • Silhouette−1 to 1, higher means tighter, better-separated clusters.
  • Davies–BouldinLower is better.
  • Calinski–HarabaszBetween/within dispersion, higher is better.
  • Elbow (inertia)Within-cluster SSE vs k, choose the bend.
  • Gap statisticCompares inertia with random reference data.
  • BIC / AICPick the number of GMM components.
  • ARI · NMINeed ground-truth labels; agreement corrected for chance.
  • V-measureHomogeneity and completeness against labels.

Dimensionality reduction, rules, anomalies

  • Explained var.Variance kept by each component (PCA, SVD).
  • ReconstructionError after encode → decode.
  • TrustworthinessAre low-dim neighbors true neighbors?
  • SupportHow often an itemset appears.
  • ConfidenceP(B | A) for rule A → B.
  • Liftconf / P(B); above 1 means positive association.
  • Precision@kShare of true anomalies in the top-k scores.

Reinforcement learning

  • Episodic returnAverage total reward per episode.
  • Cumulative regretReward lost vs the best action (bandits).
  • Sample efficiencyReturn reached per environment step.
  • Success rateShare of episodes that hit the goal.
  • StabilityVariance of return across random seeds.

Deep learning tasks

  • Top-k accuracyImage classification.
  • mAP · IoUObject detection and segmentation.
  • PerplexityLanguage model fit, lower is better.
  • BLEU · ROUGETranslation and summarization overlap.
  • FID · ISQuality and diversity of generated images.
  • Human evalPreference ratings for generative output.

Validation strategies

Hold-out splitTrain / validation / test, e.g. 70 / 15 / 15. Fast, but noisy on small data.
k-fold CVRotate k folds (5 or 10) and average the scores.
Stratified k-foldKeeps class ratios in each fold. Default for classification.
Group k-foldSame patient, user or store never in both train and test.
Time-series splitWalk-forward: always train on the past, test on the future.
Leave-one-outn folds of one sample. For very small datasets.
Nested CVInner loop tunes hyperparameters, outer loop gives an unbiased score.
Bootstrap / OOBOut-of-bag samples give a free estimate for bagged models.
Learning curvesTrain vs validation score by data size, to diagnose bias vs variance.
05 · Fitting and tuning

Optimization

Two separate layers: the optimizer that fits a model's parameters, and the search that picks its hyperparameters.

Parameter optimizersHow a model learns its weights

  • Closed formOLS, Ridge, LDA, Naive Bayes. Solved in one step.
  • Gradient descentBatch, stochastic (SGD), mini-batch.
  • Adaptive GDMomentum, Nesterov, AdaGrad, RMSProp, Adam, AdamW. Neural nets.
  • Second orderNewton, IRLS, L-BFGS. Logistic regression, GPs.
  • Coordinate descentLasso, Elastic Net.
  • QP / SMOSupport vector machines.
  • Greedy searchDecision tree splits (Gini, entropy, MSE).
  • EM / Lloyd'sGMM and k-means: alternate assign and update.
  • Eigen / SVDPCA, LSA, spectral clustering.
  • TD / BellmanQ-learning, SARSA, DQN.

Loss functionsWhat gets minimized

  • MSE / MAERegression; MAE when outliers matter less.
  • HuberRobust regression, gradient boosting.
  • Cross-entropyLogistic regression, neural classifiers, GBMs.
  • HingeSVMs: maximize the margin.
  • ExponentialAdaBoost.
  • KL divergencet-SNE, VAEs, distillation.
  • ContrastiveSelf-supervised embeddings (SimCLR, CLIP).
  • Inertiak-means within-cluster sum of squares.

RegularizationKeeping models from overfitting

L1 (Lasso) · sparse weightsL2 (Ridge) · weight decayElastic Net DropoutEarly stoppingBatch / layer norm Tree depth · min samples leafLearning rate (shrinkage)Row / column subsampling Data augmentationSVM C parameterLabel smoothing

Learning-rate schedules

Step decayCosine annealingWarmupOne-cycleReduce on plateau

Hyperparameter searchChoosing the settings

  • Grid searchEvery combination. Fine for 2 to 3 knobs.
  • Random searchSamples the space; beats grid at equal budget.
  • BayesianTPE or GP surrogate guides the next trial (Optuna, Hyperopt).
  • Hyperband / ASHAStops weak trials early (successive halving).
  • EvolutionaryGenetic algorithms, population-based training.

Knobs worth tuning

  • Random Forestn_estimators, max_depth, max_features
  • XGBoost / LGBMlearning_rate, n_estimators, max_depth, subsample
  • SVMC, gamma, kernel
  • kNNk, metric, weights
  • K-Meansk, init
  • DBSCANeps, min_samples
  • Neural netlr, batch size, layers, dropout

Small (under ~1k rows)

Naive Bayes, SVM, Gaussian Process, kNN, regularized linear models. Use repeated or leave-one-out CV.

Large (millions of rows)

LightGBM, SGD-trained linear models, Mini-Batch K-Means, neural networks.

High-dimensional, sparse

Linear SVM, Lasso, Naive Bayes, Truncated SVD before clustering.

Imbalanced classes

Class weights, SMOTE or undersampling, PR-AUC, stratified CV, threshold tuning.

Noisy labels or outliers

Random Forest, Huber loss, MAE. Avoid AdaBoost, which chases noise.

Must be explainable

Linear or logistic regression, shallow trees, or GBMs with SHAP values.
