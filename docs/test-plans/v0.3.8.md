## Known limits

- Preview (level 1): AWS only; MSK Serverless, Express brokers, MSK Connect and Replicator,
  Kubernetes, VM and Lambda runtimes are not covered yet (each pack's Pack tab lists them).
- Broker throughput has no default ceiling: AWS publishes none for Standard brokers. Set measured
  values in the organisation policy (`brokerMBps`) to turn the check on.
- Catch-up and lag are a steady-state estimate per group, not a per-partition simulation over time.
- Level 2 items still open: recorded demo, `terraform validate` in CI, console help text, migration
  test from v0.3.7 designs with an MSK queue, reviewer files.
