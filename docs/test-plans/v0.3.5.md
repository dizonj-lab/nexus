Deploy as for v0.3.4 (`git pull`, then `./deploy/canvas.sh`, or `./deploy/buddy.sh`
/ `--lab` for the app), reload once, and check the top left reads **v0.3.5**.
Automated: `./poc/tests/run-all.sh` (Docker only) must end with `ALL PASSED`.

## T1 · Flow lines do not overlap

| # | Step | Expected |
|---|---|---|
| 1.1 | New design (two services, two databases, a queue). Zoom in on the API gateway | GW1 → SVC1, GW1 → SVC2 and GW1 → IDP1 leave GW1 at different points; no two lines run on top of each other |
| 1.2 | Look where several lines reach the same component (for example Q1 or DB2) | Each arrives at its own point along the side |
| 1.3 | Drag a service so that two routes would share a vertical run | The runs sit side by side, about 12 px apart at 100 % zoom |
| 1.4 | Lines: Straight / Smooth / Elbowed (Legend) | Elbowed and Smooth keep lines apart; Straight draws direct lines as before |

Automated: `poc/tests/flows.e2e.mjs` measures every pair of drawn segments.
